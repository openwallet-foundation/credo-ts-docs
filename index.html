An OpenWallet Foundation project

Build issuers, verifiers and wallets in TypeScript

Credo is an open source framework for verifiable credentials. Issue, hold and verify SD-JWT VC, mdoc, W3C and AnonCreds credentials over OpenID4VC and DIDComm, from one codebase on Node.js and React Native.

Get started GitHub

Using an AI coding agent? Give it llms.txt or read how to point it at the docs.

issuer.ts
const agent = new Agent({
  dependencies: agentDependencies,
  modules: {
    storage, // records in Drizzle
    askar, // keys in Askar
    openid4vc: new OpenId4VcModule({
      app,
      issuer: {
        baseUrl: 'https://issuer.example.com/oid4vci',
        credentialRequestToCredentialMapper,
      },
    }),
  },
})
await agent.initialize()

const { issuer } = agent.openid4vc

// Offer a credential with the pre-authorized code flow
const offer = await issuer.createCredentialOffer({
  issuerId: 'example-issuer',
  credentialConfigurationIds: ['membership'],
  preAuthorizedCodeFlowConfig: {},
})

Paradym

by Animo

A platform for issuing and verifying credentials in EUDI and other ecosystems. It can issue and verify credentials from national EUDI wallets such as France Identité and the German d‑you. Each customer is a separate Credo tenant.

Paradym Wallet

by Animo

An open source wallet app for iOS and Android, built with Credo on React Native. It supports the EUDI flows, such as receiving a PID and presenting it with OpenID4VP, as well as DIDComm, and is a starting point for building your own wallet.

Pluggable by design

Pick the pieces you need

Every capability is a module. You choose the storage, key management, DID methods and protocols your deployment needs.

agent.ts
const agent = new Agent({
  dependencies: agentDependencies,
  modules: {
    // Records in PostgreSQL with Drizzle, keys in Askar
    storage: new DrizzleStorageModule({
      database,
      bundles: [tenantsBundle, openid4vcBundle, didcommBundle],
    }),
    askar: new AskarModule({
      askar: NativeAskar,
      enableStorage: false,
      store,
    }),
    // Replace the default cache, required with tenants
    cache: new CacheModule({ cache: new InMemoryLruCache({ limit: 500 }) }),
    tenants: new TenantsModule(),
    // Exchange protocols
    openid4vc: new OpenId4VcModule(),
    didcomm: new DidCommModule(),
  },
})
