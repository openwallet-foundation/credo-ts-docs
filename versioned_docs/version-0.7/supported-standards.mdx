## OpenID for Verifiable Credentials

Package: `@credo-ts/openid4vc`. See [OpenID4VC](./protocols/openid4vc/index.mdx).

| Specification | Versions | Roles |
| --- | --- | --- |
| [OpenID for Verifiable Credential Issuance](https://openid.net/specs/openid-4-verifiable-credential-issuance-1_0.html) | 1.0, drafts 11 to 15 | Issuer, holder |
| [OpenID for Verifiable Presentations](https://openid.net/specs/openid-4-verifiable-presentations-1_0.html) | 1.0, drafts 21 and 24 | Verifier, holder |
| [Digital Credentials Query Language](https://openid.net/specs/openid-4-verifiable-presentations-1_0.html#name-digital-credentials-query-l) (DCQL) | OpenID4VP 1.0 | Verifier, holder |
| [DIF Presentation Exchange](https://identity.foundation/presentation-exchange/spec/v2.0.0/) | 2.0, with OpenID4VP drafts only | Verifier, holder |
| [W3C Digital Credentials API](https://www.w3.org/TR/digital-credentials/) | OpenID4VP requests. For ISO 18013-7 requests, see [ISO mdoc](#iso-mdoc) | Verifier, holder |
| [OAuth 2.0 DPoP](https://www.rfc-editor.org/rfc/rfc9449), [PKCE](https://www.rfc-editor.org/rfc/rfc7636), [PAR](https://www.rfc-editor.org/rfc/rfc9126) | | Issuer, holder |
| [OAuth 2.0 Attestation-Based Client Authentication](https://datatracker.ietf.org/doc/draft-ietf-oauth-attestation-based-client-auth/) (wallet attestations) | | Issuer, holder |

## ISO mdoc

Package: `@credo-ts/core` (`agent.mdoc`). See [ISO mdoc](./protocols/mdoc/index.mdx).

| Specification | Roles | Notes |
| --- | --- | --- |
| [ISO/IEC 18013-5](https://www.iso.org/standard/69084.html) proximity presentation | Holder, verifier | Credo creates and verifies the device response. The BLE or NFC transport comes from a native module such as `expo-mdoc-data-transfer`. Reader authentication and device MAC aren't supported. |
| [ISO/IEC TS 18013-7](https://www.iso.org/standard/91154.html) Annex C, over the [Digital Credentials API](https://www.w3.org/TR/digital-credentials/) | Verifier, holder | Signed requests with reader authentication are supported. Available since 0.7.1. |
