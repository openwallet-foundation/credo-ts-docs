Credo is a TypeScript framework for issuing, holding and verifying verifiable credentials. It supports OpenID4VC and DIDComm, and formats such as SD-JWT VC, mdoc, W3C Verifiable Credentials and AnonCreds. This section takes you from an empty project to a running agent.

## Prerequisites

- Node.js 20.19 or later (Credo is tested on Node.js 22 and 24), or React Native. These pages use Expo for React Native.
- A TypeScript project that uses ES modules. Credo is published as ES modules only.

Browsers aren't supported, and Bun and Deno aren't tested. See [Platforms](../concepts/platform-and-environment.md).

## Choose your setup

Four choices come up before you write any code. If you're not sure, start with the default. You can add a protocol or format later, and an agent can use several at once.

| Choice | Default | Pick the other option when | Details |
| --- | --- | --- | --- |
| Platform | Node.js, for issuers, verifiers, mediators and cloud wallets | You build a mobile wallet: use React Native with Expo | [Platforms](../concepts/platform-and-environment.md) |
| Protocol | OpenID4VC | Use DIDComm if you need a lasting connection with messaging between agents, or AnonCreds, or your ecosystem is built on Aries. A wallet can support both | [Protocols](../protocols/index.mdx) |
| Credential format | SD-JWT VC | Your ecosystem asks for another one: mdoc for mobile driving licences, W3C VCs for Open Badges or EBSI, AnonCreds (DIDComm only) for predicates and unlinkable presentations. The EUDI Wallet uses SD-JWT VC and mdoc | [Credential formats](../credential-formats/index.mdx) |
| Storage | On a server, Drizzle on PostgreSQL for the records, as SQL tables that scale to many tenants and instances, and Askar for the keys. In a mobile wallet, Askar for both | Use SQLite instead of PostgreSQL for a single server instance or local development. A mobile wallet can also use Drizzle on `expo-sqlite` | [Storage](../agent-setup/storage/index.mdx) |

The getting started pages use Drizzle on SQLite with Askar for the keys on Node.js, and Askar on React Native. They work for any protocol and format.
